# Folder Topology

Canonical directory tree for SWS-bootstrapped manuscript projects.

The frontmatter is the source of truth — read it for the structured data. This body exists only for orientation. Rationale, antipatterns, and design history live in the architecture-sketch design doc; do not duplicate them here.

`/sws:init-project` (cycle #2) materializes `base_layout` unconditionally and each `conditional` entry only when its `trigger` evaluates true against the marker file (`references/marker-schema.md`). Per-folder `_archive/` keeps pruning local; underscore-prefixes mark SWS-managed metadata.
